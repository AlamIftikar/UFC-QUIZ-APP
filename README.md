# UFC Quiz App

## Summary
The UFC Quiz App is a simple, interactive web application that tests users' knowledge about the Ultimate Fighting Championship (UFC). Users can answer multiple-choice questions and receive a score at the end of the quiz.

## Key Features
- Stylish UI with a modern design.
- Multiple-choice questions related to UFC.
- Score tracking to display user performance.
- Responsive design suitable for various devices.

## Setup Instructions
1. Download the HTML file and save it as `index.html`.
2. Open the file in any web browser to run the application.

## Usage Instructions
- Click on one of the options presented for each question.
- After answering a question, click the "Next Question" button to proceed.
- At the end of the quiz, your score will be displayed.

## Technical Details
The application is built using:
- **HTML** for the structure of the page.
- **CSS** for styling and layout.
- **JavaScript** for the functionality and interactivity of the quiz.

The questions are stored in a JavaScript array, and event listeners are used to handle user interactions.

## Deployment Info
You can easily deploy this application on GitHub Pages. Simply push the `index.html` file to a new repository on GitHub and enable GitHub Pages in the repository settings.
